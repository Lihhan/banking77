Scope

Limits and deviations from the proposal

  • The proposal did not define how to choose τ. The rule used here is the lowest threshold with ≥ 98% selective accuracy on validation.
  • The proposal said “early stopping”. The code trains a fixed 3 epochs and keeps the best one. Every run chose epoch 3, and validation was still rising, so more epochs might help.
  • Only the learning rate was tuned for ModernBERT (3 settings). Two selected values sit at the edge of their search ranges: lr 8e-5 and TF–IDF C = 30.
  • The demo is a static Hugging Face Space with both models in the browser (fp16 ONNX ModernBERT, a JavaScript port of the TF–IDF model). Free Spaces no longer run Docker or Streamlit servers.
  • Scores are overconfident at times. In one demo query ModernBERT gave 1.00 to the wrong intent.
  • BANKING77 is English, single-domain and has no out-of-scope class. The review prompt is an uncertainty cue, not an out-of-scope detector. Nothing here supports a claim of deployment readiness.
  • Casanueva et al. (2020) report 93.66% for BERT-large and 93.36% for USE+ConveRT. These are reference points only, because the setups differ.
